# OpenSurveillanceDB — crawl policy
#
# Public civic database of visible surveillance infrastructure
# (https://github.com/Syax89/open-surveillance-db).
#
# Rationale (audit t_a07443bd):
#   - /api/*          backend endpoints, not documents — must not be indexed.
#   - /moderation     private moderator queue, gated at the worker edge
#                     (fail-closed, Basic auth / bearer token) — never index.
#   - /appelli        reserved route for the appeals flow (not public today;
#                     defensive rule in case a page is added later).
#   - /account        contributor account area, authenticated — never index.
#   - /register       account creation — never index (also reduces spam noise).
#   - /login          authentication — never index.
#
# Public info pages (/moderazione, /faq, /guide, /contatti, /licenze,
# /manifesto, /privacy, /regole, /termini, /records, /records/*) stay
# indexable: they are the project's transparency surface.
User-agent: *
Disallow: /api/
Disallow: /moderation
Disallow: /appelli
Disallow: /account
Disallow: /register
Disallow: /login
